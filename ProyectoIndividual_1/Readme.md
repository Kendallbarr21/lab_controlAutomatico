#Descripcion

El script se realizo mediante matlab este se ejecuta mediante la opción Run, el sistema le pedirá al usuario los parámetros correctos de las variables mecánicas y físicas del motor DC, el usuario debe ingresar:
El valor de la constante del motor(Kt) 
La constante de Fuerza Electromotriz(Kb),
El coeficiente de fricción(b),
La inercia del rotor (J),
El valor de la resistencia de la armadura (Ra)

 Posteriormente el sistema mostrara en la consola el valor numérico de todos los coeficientes y calculara la constante de proporcionalidad (Km) y la constante de tiempo (Tau) y los mostrara en la consola junto con la función de transferencia G(s).

 EL sistema mostrara en una grafica la curva de respuesta de esta función de transferencia y en este se visualiza el 
 Valor final esperado (y_final=Km y la aproximación obtenida de y_final=5tau), 
 El valor de la respuesta en t=Tau,
 Error de estado estacionario, 
 Error porcentual,
 Tiempo de asentamiento al 2%, 
 
El sistema mostrara ademas el valor de cada uno en la consola.
